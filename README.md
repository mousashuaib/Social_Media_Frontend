
<h1>SocialWave 🌍</h1>

<h2>Overview</h2>
<p>
    Welcome to <strong>SocialWave</strong>, a dynamic social media platform where users can connect, share, and engage with content. This application allows users to create posts, comment, like, and interact with other members, while also offering administrative tools to moderate content. Built with an intuitive interface, SocialWave provides a smooth experience for managing social interactions online.
</p>

<h2>Features</h2>

<h3>For Users:</h3>
<ul>
    <li><strong>Account Registration:</strong> Sign up securely and create your own profile.</li>
    <li><strong>Create Posts:</strong> Share your thoughts, photos, and media with your followers.</li>
    <li><strong>Comment and Like:</strong> Engage with other users' content through comments and likes.</li>
    <li><strong>Follow Users:</strong> Build connections by following other users and see their posts in your feed.</li>
    <li><strong>Profile Management:</strong> Update your profile details, including your bio and profile picture.</li>
</ul>

<h3>For Admins:</h3>
<ul>
    <li><strong>Moderate Content:</strong> Manage posts and comments to ensure community guidelines are followed.</li>
    <li><strong>User Management:</strong> Manage user accounts, including banning or reinstating users.</li>
    <li><strong>Report Generation:</strong> Generate reports on user activity, content engagement, and community growth.</li>
</ul>

<h2>Core Functionalities</h2>
<ul>
    <li><strong>Posting System:</strong> Users can create text-based and media-rich posts.</li>
    <li><strong>Commenting and Liking:</strong> Interactive features for users to engage with posts.</li>
    <li><strong>Profile Customization:</strong> Allows users to update their profile and manage their personal details.</li>
    <li><strong>User Authentication:</strong> Secure login system for users and admins.</li>
    <li><strong>Notification System:</strong> Receive real-time notifications for likes, comments, and follows.</li>
</ul>

<h2>Technical Stack</h2>
<ul>
    <li><strong>Frontend:</strong> React, HTML, CSS, JavaScript</li>
    <li><strong>Backend:</strong> Spring Boot (Java)</li>
    <li><strong>Database:</strong> PostgreSQL</li>
    <li><strong>API Testing:</strong> Postman</li>
    <li><strong>API Communication: </strong>Axios for making API requests</li>

</ul>
